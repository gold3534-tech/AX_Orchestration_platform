# Public Release Checklist

This folder is a sanitized portfolio copy of the private project.

Before uploading it to a public GitHub repository:

- Confirm no real `.env` files, API keys, access tokens, database dumps, or private customer/user data are included.
- Keep `backend/.venv`, `frontend/node_modules`, build outputs, caches, and `.git` out of the public repo.
- Review README content and remove anything that names private people, clients, accounts, or internal-only context.
- Replace private deployment URLs with public demo URLs, screenshots, or a short demo video link.
- Use fake/test credentials only in examples and tests.
- Create the public repository from inside this folder, not from the original private project folder.

Suggested resume wording:

```text
AX Platform - Full-stack AI workflow builder
Public portfolio repository: <public repo URL>
Private production repository available upon request
```
